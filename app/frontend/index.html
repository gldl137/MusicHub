OpenList（strm 播放）配置
内网基地址
OpenList 内网直连地址（如 http://192.168.2.6:5244）。客户端在内网时，strm 播放 302 跳此地址直连
外网基地址
OpenList 外网穿透地址（如 http://xxx.cpolar.top）。客户端在外网时，strm 302 跳「外网基地址 + 文件名路径」；若外网需 token，可一并拼到地址里
strm 文件内容为一行完整内网直链；播放时按客户端 IP 自动选「内网基地址」或「外网基地址 + 文件名路径」302 跳转，服务端不代理音频流。
客户端直连（307）
播放直连（307）
开启：箭头音乐等客户端播放网络歌曲时，服务器返回 307 直链，客户端直连音频 CDN；关闭：服务器代理转发音频流
封面直连（307）
开启：客户端请求网络歌曲封面时，服务器返回 307 直链，客户端直连图片源；关闭：服务器下载封面并落盘缓存后返回（默认）
注意：部分第三方 Subsonic 安卓客户端（如箭头音乐）不支持图片 307 重定向，开启后可能出现封面空白；如遇此情况请关闭此开关，切换为后端代理模式。

LX 音源
用于给左侧「LX」专区的排行榜 / 热门歌单歌曲提供播放解析（落雪音乐自定义音源，musicUrl）。
支持平台：酷我 / 酷狗 / QQ音乐 / 网易云 / 咪咕。音源脚本以 Node 沙箱运行，请只导入可信来源的音源。
可安装并同时启用多个音源：同名文件不会覆盖，会自动另存为 xxx(2).js，多个音源在列表中并排共存； 播放按列表顺序解析，某个音源失败时自动切换到下一个已启用音源； 播放器上的「切换音源」可指定优先使用哪个音源（优先级会按平台记住）。
